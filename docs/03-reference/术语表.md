# 术语表

> **本页速览**
> - 按 **8 个类别**归类,同一类的词放在一起 —— ★ 因为"混淆"通常发生在同类词之间。
> - ★ 每个词条只给**一句话**,后面括号里是"在哪见过"的链接 —— 想深入就点过去。
> - ★★ 最该先搞清的 5 个词:**SPI**、**归一**、**原子性**、**fail-open**、**取消传播**。
> - ⚠️ 有些词在本项目里有**特定含义**,和通用理解不完全一样 —— 都标了 ★ 提醒。
> - ★ 遇到文档里看不懂的词,先来这里查;查不到 → 去 [FAQ](FAQ.md) 看是不是个"问题"而不是"词"。
>

## 2. ★★ Reactor / WebFlux(最容易看错的一类)

| 术语 | 一句话 | 在哪见过 |
|---|---|---|
| **WebFlux** | Spring 的**响应式** Web 框架。★ 本项目用它,**不是 MVC** | [架构总览](../00-map/架构总览.md) |
| **Reactor** | WebFlux 底下的响应式库,提供 `Mono` / `Flux` | — |
| **Mono** | ★ **0 或 1** 个结果的数据流 | [类-Provider](../01-modules/02-上游渠道抽象/类-Provider.md) |
| **Flux** | ★ **0 到 N** 个结果的数据流 | [类-Provider](../01-modules/02-上游渠道抽象/类-Provider.md) |
| ★ **事件循环(Event Loop)** | ★★ 少数几个线程轮流处理**所有**连接 | [启动流程](../02-flows/启动流程.md) |
| ★★ **阻塞事件循环** | ★ 在事件循环线程里干等,会**拖垮它服务的所有连接** | [流式流程·卡点 3](../02-flows/流式请求处理流程.md) |
| **背压(Backpressure)** | 下游消费不过来时,向上游**要求减速** | — |
| ★★ **取消传播** | 客户端断开 → WebFlux **自动**取消上游请求。★★ 省上游的钱就靠它 | [流式流程](../02-flows/流式请求处理流程.md) |
| **`SignalType.CANCEL`** | 取消信号。★ 在 `doFinally` 里能把它和"正常读完"分开 | [类-OpenAiCompatibleProvider](../01-modules/02-上游渠道抽象/类-OpenAiCompatibleProvider.md) |
| ★ **`concatMap` vs `flatMap`** | ★ 前者**保序**,后者**并发**。★★ 流式必须保序 | [流式流程](../02-flows/流式请求处理流程.md) |
| ★ **`collectList()`** | ★ 把流**攒成一整个 List** —— ★★ 用它 = 悄悄退回批处理 | [流式流程·卡点 3](../02-flows/流式请求处理流程.md) |
| ★ **`block()`** | ★ 阻塞地等结果。★★ WebFlux 里在事件循环上调用是大忌 | [启动流程](../02-flows/启动流程.md) |
| **`doFinally`** | ★ 流结束(**无论怎么结束**)时执行 —— ★ 本项目**唯一的取消观测点** | [测试-流式与取消传播](../01-modules/07-测试验证/测试-流式与取消传播.md) |
| **`onErrorMap`** | ★ 把一种异常**映射成**另一种 —— ★ 本项目用它造 `UpstreamIdleTimeoutException` | [类-UpstreamIdleTimeoutException](../01-modules/05-错误处理/类-UpstreamIdleTimeoutException.md) |
| ★ **`Flux.timeout()`** | ★★ 语义是**相邻两元素之间**的超时,**每个元素都重置一次** | [流式流程·卡点 5](../02-flows/流式请求处理流程.md) |
| ★ **公共的 WebClient / 私有的事件循环** | ★ 超时设在共用 `HttpClient` 上 → **所有渠道共享** | [启动流程](../02-flows/启动流程.md) |

| 术语 | 一句话 | 在哪见过 |
|---|---|---|

| **Lua 脚本** | ★ 在 **Redis 内部**执行的脚本 —— ★★ 天然的原子性载体 | [脚本-token_bucket.lua](../01-modules/06-限流/脚本-token_bucket.lua.md) |
| ★ **`cjson`** | Redis 里 Lua 的 JSON 库。★ 用它返回结构化结果,比拼字符串靠谱 | [脚本-token_bucket.lua](../01-modules/06-限流/脚本-token_bucket.lua.md) |
| **`redis.call('TIME')`** | ★ 取 Redis 服务端时间 —— ★★ 作为**唯一时钟源**,避免各实例时间不一致 | [脚本-token_bucket.lua](../01-modules/06-限流/脚本-token_bucket.lua.md) |
| ★ **时钟回拨** | ★ 服务器时间被 NTP 往回调 → ★ 脚本里做了保护 | [脚本-token_bucket.lua](../01-modules/06-限流/脚本-token_bucket.lua.md) |
| ★★ **fail-open** | ★★ 限流器**坏了就放行**。道理:它是**保护性**组件,不是**功能性**组件 | [类-RedisTokenBucketLimiter](../01-modules/06-限流/类-RedisTokenBucketLimiter.md) |
| ★★ **fail-closed** | ★★ 限流器坏了就**拒绝**。★ 给成本敏感的团队(超卖=真金白银) | [测试-限流与并发](../01-modules/07-测试验证/测试-限流与并发.md) |
| ★ **水位(remaining)** | 桶里还剩几个。★★ **未知时必须报 -1,不能编一个数字** | [类-RateLimitDecision](../01-modules/06-限流/类-RateLimitDecision.md) |
| ★ **三态决策** | ★★ `ALLOWED`(200) / `DENIED`(429) / `UNAVAILABLE`(503) —— **三种,不是两种** | [类-RateLimitDecision](../01-modules/06-限流/类-RateLimitDecision.md) |
| ★ **429 vs 503** | ★★ 429="你太快了"(客户端退避);503="我坏了"(运维该看) | [方法速查表](方法速查表.md) |
| **限流维度** | ★ 按什么键限 —— 本项目是**客户端 ID,缺了回落来源 IP** | [类-RateLimitWebFilter-深入](../01-modules/06-限流/类-RateLimitWebFilter-深入.md) |
